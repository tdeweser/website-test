Flat note block with an accent left rule — for source notes (Bron / Toelichting), key takeaways and alerts.

```jsx
<Callout tone="brand" title="Kernpunt">
  Landelijke basis, lokaal maatwerk.
</Callout>
<Callout tone="neutral">Bron: CBS micro-data, n = 282.421.</Callout>
```

Tones: `neutral` / `brand` / `info` / `positive`. `title` is optional.
