Small uppercase DM Mono eyebrow / kicker / data label — a core IPE brand cue (mono for labels and data).

```jsx
<MonoLabel bullet>Onderzoek · 2026</MonoLabel>
<MonoLabel color="var(--ipe-aqua)">Policy paper</MonoLabel>
```

`bullet` adds a leading red square. Keep it short; it uppercases automatically with wide tracking.
