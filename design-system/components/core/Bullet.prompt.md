The signature IPE red-square bullet (▪) — the brand's list marker, replacing round dots.

```jsx
<BulletList items={["Landelijke basis", "Lokaal maatwerk", "Eerlijker en eenvoudiger"]} />
<span><Bullet /> inline marker</span>
```

`Bullet` renders one square (`size`, `color`). `BulletList` renders an `<ul>` of items each prefixed with the square, baseline-aligned to the text.
