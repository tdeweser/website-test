Pill chip for topics, categories and filters — a rare rounded shape in the otherwise rectilinear system.

```jsx
<Tag color="red">Armoedebeleid</Tag>
<Tag color="aqua" solid>Onderzoek</Tag>
```

Colours: `red` / `aqua` / `green` / `blue` / `gray`. `solid` swaps the soft tint for a filled accent. Keep labels short, sentence case.
