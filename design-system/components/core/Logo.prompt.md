The IPE stacked wordmark in DM Mono — a coloured block holding "Instituut / voor" with "Publieke / Economie" below. For official/print use prefer the supplied vector logo in `assets/logo/`; use this for on-brand web/app UI.

```jsx
<Logo size={48} />
<Logo size={40} variant="inverted" />
```

`size` scales the whole mark. `variant="inverted"` swaps the block colours (for dark/light footers). Never distort, recolour off-palette, tilt, or centre the logo.
